# 离线索引实践

## 1. 说明

离线索引适合学习型 RAG 项目，因为它把数据准备、向量生成和检索验证拆开。RAGHub 当前使用脚本构建 chunks 与 embeddings，而不是在请求时实时切块和编码。这样做的优点是可复现、易调试、便于提交 data/processed 产物；缺点是每次文档更新都要重建索引，数据规模大时会变慢。面试中可以说明：先做离线索引是为了验证主链路，后续才考虑增量更新、向量数据库和后台任务。
