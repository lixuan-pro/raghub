# Source Grounding 实践

## 1. 说明

Source grounding 的目标是让回答中的结论能被检索片段支撑。RAGHub 通过 sources、retrieved_chunks、score 和 content_preview 暴露证据，但这还不等于严格的引用校验。真实风险包括：片段相关但不直接支持答案，多个接口字段被相邻文档混在一起，或者 demo corpus 问题命中项目文档。当前阶段用人工 LLM review 和 bad_cases.md 记录这些风险。后续可以要求模型逐条说明哪个 source 支撑哪个结论，也可以增加 answer-grounding 检查。
