# 知识文档责任人策略

## 1. 说明

这是自建 demo corpus，用于模拟 AI 应用后端项目中的知识库维护规则。每类文档都应有责任人：API 设计由后端维护，eval 由测试或算法同学维护，部署边界由工程负责人维护，安全与 API key 策略由项目负责人复核。文档更新后需要记录变更原因，并触发索引重建和小样本 eval。对于 RAGHub 这种学习型项目，责任人可以是同一个开发者，但流程仍要保留，便于面试时说明如何避免知识库长期失真。
